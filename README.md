# The Daily Atlas - 19 November 2026

This is an entry for the `news-image-20261119` competition on [make.fun](https://make.fun/c/news-image-20261119).

The image shows a newspaper front page, "THE DAILY ATLAS", summarizing the world news of Thursday 19 November 2026.

## How it's built
- `draw.py` renders the page (1024x1024 PNG) using Python, Pillow, and numpy, with photographic artwork generated via Recraft for featured stories and procedural banners for others.
- `main.py` deploys the `entry.png` to the output directory.

## How to run
1. Install dependencies: `pip install pillow numpy`
2. Run `python3 main.py` (ensure `entry.png` is present in the same directory).
